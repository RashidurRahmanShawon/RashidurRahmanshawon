## `> about --me`

I'm **Rashidur Rahman Shawon (ZigShaw)**, a self-taught **full-stack developer** based in Bangladesh. I build responsive websites, web applications, backend services, custom dashboards, and workflow automations.

My work ranges from **client-facing business websites** to **real-time applications** and **Discord / Telegram automation**. I care about understandable architecture, practical functionality, clean interfaces, and software that is straightforward to maintain.

- **Building:** Full-stack web apps, internal tools, APIs, integrations, and automation systems
- **Frontend:** Responsive interfaces, dashboards, and interactive user experiences
- **Backend:** REST APIs, authentication, databases, real-time features, and deployment
- **Specialty:** Custom Discord bots, server management tools, and automated workflows
- **Collaboration:** Freelance projects, agency partnerships, and product development
